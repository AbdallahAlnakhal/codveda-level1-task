# Full-Stack Web Application - Codveda Internship

This repository contains the complete and fully implemented tasks for the Codveda Full-Stack Internship, structured progressively across three levels.

---

## 🚀 Project Overview & Completed Levels

### 🔹 Level 1: Basic Setup & REST API
- **Backend:** Node.js and Express server with initial REST API routes for task CRUD operations.
- **Frontend:** Clean and responsive UI using HTML, CSS, and Vanilla JavaScript.
- **Version Control:** Git workflow and repository initialization.

### 🔹 Level 2: Database Integration & User Authentication
- **Database Integration:** Integrated **SQLite** for persistent storage of users and tasks.
- **Authentication:** Implemented user registration and login endpoints utilizing **bcryptjs** for password hashing.
- **Session Management:** Secure user state handled via `localStorage`.

### 🔹 Level 3: Advanced Features & Optimization (Completed)
- **Task Editing (Update):** Added `PUT /api/tasks/:id` endpoint allowing users to modify existing tasks inline.
- **Real-time Search & Filtering:** Client-side task filtering by search query.
- **Improved UX & Error Handling:** Comprehensive feedback on input validation and server errors.

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** SQLite3
- **Security:** Bcryptjs
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
